## 💻 Sobre o Projeto
O **Be The Hero** foi desenvolvido durante a Semana OmniStack 11 da Rocketseat. É uma aplicação completa que permite que ONGs cadastrem casos de necessidade (como despesas médicas para animais ou mantimentos) e que heróis (usuários) entrem em contato para ajudar via WhatsApp ou E-mail.

## 🛠️ Tecnologias
Este projeto foi construído utilizando a stack **Node, React e React Native**:

- **Backend**: Node.js com Express
- **Frontend**: React.js com integração de API (Axios)
- **Mobile**: React Native (Expo)
- **Banco de Dados**: SQLite com Knex.js
- **Testes**: Jest (Integração e Unitários)

## ⚙️ Funcionalidades
- Cadastro e Login de ONGs.
- Cadastro e exclusão de casos específicos.
- Listagem de casos no Frontend e no App Mobile.
- Integração de contato direto com a ONG através de Deep Linking.

## 🚀 Como Executar
1. Clone o repositório.
2. No diretório `backend`, rode `npm install` e `npm start`.
3. No diretório `frontend`, rode `npm install` e `npm start`.
4. (Opcional) No diretório `mobile`, rode `npm install` e `expo start`.
